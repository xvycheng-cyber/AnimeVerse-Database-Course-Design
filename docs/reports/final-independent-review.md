## 3. 数据库与安全审查

应用账户实测为 `Chengzi@localhost`，权限如下：

```text
GRANT SELECT, INSERT, UPDATE, DELETE, EXECUTE, SHOW VIEW
ON `anime_platform`.* TO `Chengzi`@`localhost`;
```

未发现全局 DBA 权限、跨库业务权限或触发器元数据权限被授予应用账户。建表、触发器和账户初始化使用管理员连接，业务运行使用最小权限账户。

安全检查覆盖：

- BCrypt 密码哈希，数据库不保存明文密码。
- JWT 鉴权与 ADMIN/USER 角色边界。
- 无令牌访问管理接口返回 401，普通用户返回 403。
- 无效 JWT 不阻断公开动漫接口，但受保护资料接口返回 401。
- 停用账户登录返回 403。
- SQL 注入式关键词不扩大结果集。
- 前端源码不存在 `v-html`。
- 实验室收藏、动漫新增和动漫删除写操作产生审计记录。
- `.env` 不进入 Git 或最终 ZIP，仓库仅保留 `.env.example`。

## 8. 残余风险

1. 远程 AniList 封面依赖网络；动漫 ID 1 有本地备用封面，但其他远程封面断网时可能显示回退状态。
2. Vite 构建存在非阻断大 chunk 警告，主要来自 ECharts 和依赖聚合。
3. 当前为本地课程设计环境，未实现生产级登录限流、CSP、密钥托管和集中审计归档。
4. JWT 存储在浏览器 `localStorage`，属于课程演示常见方案，公网部署需重新评估。
5. 写入型存储过程自行管理事务，当前后端不嵌套调用；若未来组合多个写过程，需要重新设计事务边界。
