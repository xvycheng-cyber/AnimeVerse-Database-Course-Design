# 星漫云部署与运行手册

## 1. 适用范围

本手册用于 Windows 10/11 本地课程演示环境。系统包含 MySQL 8.0 数据库、Java 17 Spring Boot 后端和 Vue 3 前端。默认地址：

- 前端：`http://localhost:5173`
- 后端 API：`http://localhost:8080/api`
- OpenAPI：`http://localhost:8080/v3/api-docs`
- MySQL：`localhost:3306`，数据库 `anime_platform`

正式数据库必须使用 MySQL。项目不会回退到 SQLite、H2 或内存数据库。

## 2. 环境要求

| 软件 | 要求 |
|---|---|
| Windows PowerShell | PowerShell 7 或 Windows PowerShell 5.1 |
| MySQL | 8.0.x，含 `mysql.exe`、InnoDB、utf8mb4 |
| JDK | 17 |
| Maven | 3.9.x |
| Node.js | 20 或兼容版本 |
| npm | 随 Node.js 安装 |
| 浏览器 | Chrome 或 Edge |

如果 `java -version` 不是 17，请设置 `JAVA_HOME` 指向 JDK 17。项目启动脚本也会在用户 `.codex/tools`、`C:\Program Files\Java` 和 PATH 中寻找 JDK 17。

## 3. 目录说明

| 目录 | 内容 |
|---|---|
| `database/` | 表、种子、查询、视图、触发器、过程、函数、游标、事务和测试 |
| `backend/` | Spring Boot REST API |
| `frontend/` | Vue 3 用户端和管理端 |
| `docs/` | 设计文档、图表、截图、报告和手册 |
| `scripts/` | 初始化、启动、测试、渲染和打包脚本 |
| `dist/` | 最终 ZIP 交付包 |

## 4. 配置本地环境

在仓库根目录将 `.env.example` 复制为 `.env`，填写本地值：

```text
DB_HOST=localhost
DB_PORT=3306
DB_NAME=anime_platform
DB_USER=Chengzi
DB_PASSWORD=<本地应用账户密码>

MYSQL_ADMIN_USER=root
MYSQL_ADMIN_PASSWORD=<本地 MySQL 管理员密码>

SERVER_PORT=8080
JWT_SECRET=<至少 32 个 UTF-8 字节的随机字符串>
JWT_EXPIRATION_MINUTES=120
APP_CORS_ORIGIN=http://localhost:5173,http://127.0.0.1:5173

VITE_API_BASE_URL=http://localhost:8080/api
```

`.env` 已被 `.gitignore` 忽略。不要把真实密码写入 `.env.example`、SQL、Markdown 或 Git 提交。

## 5. 初始化数据库

### 5.1 首次初始化

从仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-database.ps1
```

脚本会：

1. 检查 MySQL 客户端。
2. 检查 `anime_platform` 是否存在；存在时不删除。
3. 检查 `Chengzi@localhost` 是否存在；不存在时创建，存在时刷新密码。
4. 仅授予目标库的 `SELECT`、`INSERT`、`UPDATE`、`DELETE`、`EXECUTE`、`SHOW VIEW`。
5. 检查项目表，拒绝覆盖含未知表的数据库。
6. 依次加载表、种子、封面、函数、视图、过程、触发器和计数回算。
7. 使用应用账户重新连接并输出种子计数。

期望种子计数：

```text
8 30 60 20 6 10 30 30 20
```

含义依次为厂商、动漫、剧集、制作人员、平台、用户、收藏、观看记录和评论。

### 5.2 重复初始化

再次执行同一命令是安全的。脚本不会删除数据库，不会清空业务表，使用 `INSERT IGNORE`、`CREATE OR REPLACE` 和按名称重建对象完成幂等更新。

如果数据库中已有项目表之外的表，脚本默认停止。确认这些表属于本机其他课程数据后，才可考虑 `-AllowAdditionalTables`；不要为了绕过检查而破坏其他数据。

### 5.3 不自动重建

项目不提供自动 `DROP DATABASE`。需要完全重建时，必须先备份，再由数据库管理员单独执行人工确认的 SQL，并重新运行初始化脚本。自动测试和日常启动均不会删除数据库。

## 6. 启动后端

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1
```

脚本会读取 `.env`、验证必需变量、定位 Java 17 和 Maven、构建 JAR，然后启动 Spring Boot。首次启动可看到类似日志：

```text
Starting AnimeVerseApplication ... using Java 17
Tomcat started on port 8080
Started AnimeVerseApplication
```

后台已经构建时可跳过构建：

```powershell
.\scripts\start-backend.ps1 -SkipBuild
```

停止后端：在运行窗口按 `Ctrl+C`。

## 7. 启动前端

另开 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-frontend.ps1
```

脚本会在缺少 `node_modules` 时执行 `npm install`，随后启动 Vite。打开：

```text
http://localhost:5173
```

停止前端：在运行窗口按 `Ctrl+C`。

## 9. 手工构建

### 9.1 后端

```powershell
$env:JAVA_HOME='<JDK 17 路径>'
cd .\backend
mvn clean package
```

生成：

```text
backend\target\animeverse-backend-1.0.0.jar
```

### 9.2 前端

```powershell
cd .\frontend
npm install
npm test
npm run build
```

生成：

```text
frontend\dist\
```
